# Timestamped recordings
Stop recording and wait for Saved. Each completed or failed run with data saves a CSV and raw text log in private app storage. Home / Recorded files lists saved pairs and shares both via Android share sheet. No storage permission or Room required. A failed save blocks a new recording until retry succeeds; clipboard export remains available. Files survive normal app restarts, not uninstall or clearing app data. A process kill during recording can still lose unsaved samples. Filename uses recording start time, timezone and unique suffix. Verify by making two simulator recordings, restarting and sharing both. Run ./gradlew :app:testDebugUnitTest :app:assembleDebug before merging.
